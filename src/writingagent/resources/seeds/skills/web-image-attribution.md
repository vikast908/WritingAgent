## When to apply
Any time a photo or web-sourced illustration is included.

## Technique
- Use only freely-licensed sources (Wikimedia Commons, public domain, CC-BY). Verify the license.
- Embed as Markdown: `![<descriptive alt>](<image-url>)`
- ALWAYS credit on the next line, italicized:
  `*Figure N: <caption>. Source: "<title>" by <author>, <license>, via <source> (<url>).*`
- Never include an image whose author or license is unknown.

## Anti-pattern it replaces
Dropping in images with no credit or license - a copyright risk and an attribution failure.
