## When to apply
Non-fiction or technical chapters with figures, tables, code listings, or callouts.

## Technique
- Number figures/tables/listings per chapter (Figure 2.1, Table 2.1, Listing 2.1) with a caption.
- Use callout blocks for notes/warnings/tips: `> **Note:** ...`, `> **Warning:** ...`.
- Keep code in fenced blocks with a language tag; introduce each listing in the prose first.
- Cross-reference by number, not spatial position.

## Anti-pattern it replaces
Unlabeled figures and code, and "as shown below" references that break when layout reflows.
