# Maintainer dev journals

These are the maintainer's working logs — **not** user or contributor documentation. They're
kept in the repo for continuity across machines and sessions, tucked under `docs/dev/` to keep
the project root focused on the files a new contributor actually needs.

- **`resume.md`** — the running session log (newest entry on top): what changed last session and
  the concrete next step. Durable *decisions* live in [`../../plan.md`](../../plan.md), not here.
- **`test.md`** — the verification log: what was run, where, and what it proved, per session.

If you're here to **use** or **contribute to** Writing Agent, start with the root
[`README.md`](../../README.md), [`CONTRIBUTING.md`](../../CONTRIBUTING.md), and the architecture
spec [`plan.md`](../../plan.md).
