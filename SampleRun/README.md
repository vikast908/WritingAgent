# SampleRun — fully autonomous book generation

This folder captures one **end-to-end, no-human-in-the-loop** book produced by Writing Agent,
on **OpenRouter + DeepSeek** (V4 Pro for planner/writer/consolidation, V4 Flash for the rest).
Everything here was generated by the system; the only human input was the seed abstract and the
`--autonomous` flag.

## The book

- **Title:** *The Misprint File*
- **Genre / tone:** Dystopian noir thriller — bureaucratic absurdity, ticking-clock paranoia.
- **Seed abstract (the only human input):** *"In a town where every citizen receives a sealed
  envelope at birth naming the exact date they will die, a young postal carrier finds a misprinted
  envelope addressed to herself — and sets out to discover who writes the dates, and whether hers
  can be unwritten."*
- **Kickoff:** `new --autonomous --pick 1 --chapters 3 --max-revisions 1` → `run` → `export`.

## What ran (autonomously)

| Phase | Outcome |
|---|---|
| **Planner** | Proposed 3 distinct directions; auto-picked #1 ("The Misprint File"); expanded to a full plan |
| **TOC** | 3 chapter blueprints (purpose / setup / payoff / dependencies) |
| **Write → Critique** (per chapter) | Ch1: revise→revise→**cap → committed best draft**. Ch2: revise→**approved** (0 blocking, conf 0.95). Ch3: revise→revise→**cap → committed best draft** |
| **Commit** | Each chapter: prose + summary + canon extraction (25 characters, world rules, timeline) + FTS index |
| **Consolidation** (final) | Found **5 contradictions, 12 unresolved threads** (reported; autonomous mode did not pause) |
| **Production** | Decided + generated **5 front-matter + 2 back-matter** components; assembled `manuscript.md` |
| **Learner** | Distilled **5 reusable craft skills** + a 5-item watch-list into the per-user library |
| **Export** | `manuscript.pdf` — 9 pages |

## Files

```
SampleRun/
  manuscript.pdf          ← the deliverable (also in book/)
  run-log.txt             ← full console log of the autonomous run
  book/                   ← complete book folder
    book_plan.md  plan.json  toc.md  toc.json  run_state.json  revision_log.md
    manuscript.md  manuscript.pdf
    chapters/   ch01–03 .md + .summary.md
    eval/       ch01–03 .json  (critic verdicts: blocking issues, confidence)
    canon/      characters/*.md (25 extracted), world_rules.md, timeline.md
    consolidation/final.md   (the contradiction/unresolved-thread audit)
    frontmatter/ title-page, copyright, dedication, epigraph, table-of-contents
    backmatter/  about-the-author, acknowledgments
  learned/                ← per-user learning this book produced (carries to future books)
    skills/*.md           (5 genre-tagged craft skills, e.g. silent-misprint-handling)
    watch_list.md
    skills_index.json     (efficacy counters for skill promotion)
```

## What this demonstrates

- **True autonomy.** The critic is strict (it rejected ch1 and ch3 even at high confidence);
  autonomous mode committed the best draft at the revision cap instead of pausing. Nothing waited
  on a human.
- **Self-improving memory.** The 5 learned skills are genuinely derived from this book's world —
  e.g. *silent-misprint-handling* encodes "the Bureau detains via plainclothes signals, never
  alarms," straight from the book's own world rules. These are now retrievable for future
  thrillers by the same user.
- **Production discipline.** Author/publishing facts it can't know are left as clear placeholders
  (`[AUTHOR NAME]`, `[YEAR]`, `[ISBN]`) rather than fabricated.
- **Continuity tracking.** 25 characters, world rules, and a timeline were extracted into queryable
  canon as chapters committed.

## Honest caveats

- **Consolidation flagged 5 contradictions / 12 unresolved threads.** Autonomous mode reports but
  doesn't act on these. A human-in-the-loop run (the default) would pause on contradictions
  (`escalate_on_contradiction`), and more revision rounds (`--max-revisions`) would tighten quality.
  This sample favored a hands-off demo over polish.
- **Manuscript title appears twice** at the very top (assembler H1 + the title-page component) —
  a known cosmetic nit in `_assemble_manuscript`.
- A real bug was found and fixed *during* this run: DeepSeek V4 is a reasoning model, and the
  critic's token budget was too low — internal reasoning truncated the JSON to empty. Fixed via
  empty-response detection + retry and higher `max_tokens` on reasoning-heavy nodes.

## Reproduce

```bash
pip install -e .                          # or: pip install writing-agent  (set a host key in .env)
python writingagent.py new --autonomous --pick 1 --chapters 3 --max-revisions 1 \
  --abstract "<your idea>"
python writingagent.py run
python writingagent.py export
```
